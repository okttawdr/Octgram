# Mulai di sini

1. Baca `semua_ada_disini.md` dari bagian 0.
2. Rotasi seluruh secret yang pernah berada di ZIP lama.
3. Pilih jalur SQL yang tepat: project kosong memakai satu `schema.sql`; database
   lama memakai 002 → 003 → 004 → 005.
4. Isi `.env` dari `.env.example`, jalankan `npm ci` dan `npm run verify`.
5. Ikuti bagian Vercel dan checklist produksi di panduan utama.

Jangan commit atau kirim file `.env`.
